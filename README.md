# Customer_Behavior_Analysis
Data Analytics Projects Showcasing Customer Behavior Analysis Using Python , SQL And Power BI

Overview
  This project demonstrates a complete data analytics workflow — from data loading and cleaning to visualization and reporting. The goal is to extract meaningful insights from the dataset using Python, SQL, and Power BI.
  The project covers:
    Data preprocessing and cleaning
    Exploratory Data Analysis (EDA)
    SQL-based analysis using PostgreSQL (Neon Console)
    Interactive dashboard creation using Power BI
    Final report and presentation
Dataset
  The dataset contains customer purchase and transaction-related data.
  Includes attributes such as:
    Customer ID
    Gender
    Purchase Amount
    Product Details
    Discount Applied
    Shipping Type
    Subscription Status
Tools & Technologies
    Python (Pandas, NumPy, Matplotlib, Seaborn)
    PostgreSQL (via Neon Console Online Editor)
    Power BI (for dashboard creation)
    Gamma (for presentation/PPT creation)
Project Steps
  1. Data Loading (Python)
    Loaded dataset using Pandas
    Checked structure, datatypes, and missing values
  2. Data Cleaning
    Handled missing values
    Removed duplicates
    Standardized column formats
  3. Exploratory Data Analysis (EDA)
    Analyzed distributions and trends
    Compared customer segments
    Identified patterns using visualizations
  4. SQL Analysis (PostgreSQL - Neon)
    Uploaded cleaned dataset to Neon PostgreSQL database
    Executed analytical queries such as:
    Revenue by gender
    Discount impact analysis
    Top-performing products
    Customer segmentation
  5. Dashboard Creation (Power BI)
    Connected dataset to Power BI
    Built interactive visualizations:
    Revenue breakdown
    Customer segmentation
    Product performance
    Designed a user-friendly dashboard
  6. Reporting & Presentation
    Created a structured report summarizing insights
    Developed a presentation using Gamma for storytelling
Dashboard
The Power BI dashboard includes:
    Revenue analysis by different categories
    Customer behavior insights  
    Product performance metrics
    Filters for interactive exploration
Results & Insights
    Identified key revenue-driving customer segments
    Analyzed the impact of discounts on sales
Discovered top-rated and high-performing products
Observed differences in spending behavior (e.g., subscribers vs non-subscribers)
